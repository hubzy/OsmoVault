## 二轮：GitHub 调研 + FrameCut 规范/功能移植（晚）
- **GitHub 调研结论**（用户想「同框架项目复制进来」）：
  - FrameCut（github.com/lidedongsn/frame-cut，MIT，SwiftUI+AVFoundation，macOS14+）：最接近剪映的完整开源 Mac vlog 剪辑器，但它是 XcodeGen 完整应用（核心在 Packages/FrameCutKit，依赖 WhisperKit/Metal，Apple Silicon only），数据模型（FCCore Project/Track/Clip）与 OsmoVault 的 Asset/GRDB 完全不同——整体搬=重写，不可行；**采用其布局/字号规范并移植可落地功能**。
  - Kadr（SteliyanH/kadr，Apache 2.0，Swift 6）：kadr-ui 有 TimelineView 组件但是 DSL 合成引擎，引入=替换 QuickCutService。未采用。
  - capcutsdk/VideoEditor（单 commit AI 脚手架）、VidPare（单视频裁剪器）：功能不足，未采用。
  - FrameCut 布局规范（已照搬）：顶栏 44pt / 工具条 36pt / 检查条 40pt / 1px 分隔线分区 / 区内水平边距 12 / 工具条按钮 28×26 / 字号五档 13-12-11-10-9 / 顶部胶囊 toast 自动消失 / 顶栏右侧放导出主操作。
- **功能移植**（已实现）：
  - ⌘B 分割：播放头处把所在片段一分为二（时间轴秒÷变速换算源秒），选中后半段。
  - 边缘拖拽修剪：选中片段显示左右白色把手（TrimHandle，DragGesture），dx点÷每秒像素×变速换算源秒，pushUndo。
  - 变速 0.25×–4×：CutSegment 加 speed 字段，duration=(end-start)/speed；QuickCutService.prepare 用 track.scaleTimeRange 音画同步缩放；检查条 Stepper；片段卡龟兔徽章。预览 audioTimePitchAlgorithm=.spectral 保原调，导出变调（已知限制）。
  - 时间线缩放：@AppStorage quickCut.pointsPerSecond（8–120），对数滑条+⌘0 适应窗口（GeometryReader 记 timelineViewport）；clipWidth=duration×pps，下限 48。
  - 素材池打通图库：搜索（文件名/地点）+ segmented 筛选（全部/收藏/评分≥4，连 Asset.isFavorite/rating），poolAssets 供自动出片；ResizableSplit 从 MainWindowView 移出 private 供复用（key quickCut.poolWidth）。
